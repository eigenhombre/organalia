#+OPTIONS: toc:nil num:nil
This WORK IN PROGRESS program generates Org Mode output from a
Clojure program, similar to what
Marginalia[fn::https://github.com/clj-commons/marginalia] does for
Clojure-to-HTML.  If you are looking at an HTML or PDF version of
this file, it was generated by the program itself.

There is also "Org-Babel" which works the other way, by embedding
code inside an Org doc, but I find it easier to work primarily in
~clojure-mode~, leveraging Paredit and various CIDER features, and
then using Org Mode as an intermediate format prior to exporting to
PDF and/or HTML.

N.B.: to generate ~README.org~, run `make readme` in the repository
root.

Ideally, we want to accomplish the conversion without writing an
entire parser from scratch.  ~rewrite-clj~ already parses Clojure
source into a tree of nodes, preserving comments and whitespace, so
we use that instead of mutating the reader (which is the approach
Marginalia takes).

This namespace declaration picks up the needed ~rewrite-clj~
functions:

#+BEGIN_SRC
(ns organalia.main
  (:gen-class)
  (:require [clojure.string :as str]
            [clojure.tools.cli :as cli]
            [clojure.core.match :refer [match]]
            [rewrite-clj.node :as n]
            [rewrite-clj.parser :refer [parse-string-all]]))
#+END_SRC

~parse-string-all~ returns a map-like thing (a
"~FormsNode~") with one key: ~:children~.  ~:children~ is a
collection of things: newlines, comments, keywords, seqs, etc.

For example, given this example program,

#+BEGIN_SRC
(def example-program "

;; This is my Clojure program

;; There are many like it, but this one is mine.
;; Or is it?

:a

(def a-form 333)
")
#+END_SRC

We want subsequent comment lines not separated by newlines to be
combined into a single paragraph.

(:s (n/comment-node "hi\n"))
#+END_SRC

Something to put paragraphs into:

#+BEGIN_SRC
(defrecord Paragraph [s])
#+END_SRC


#+BEGIN_SRC
(defn- make-paragraph [s] (Paragraph. s))
#+END_SRC


#+BEGIN_SRC
(defn- paragraph? [x] (instance? Paragraph x))
#+END_SRC

We carry forward a little state:

#+BEGIN_SRC
(defn- next-state
  ([item]
   (next-state nil item))
  ([prev-state item]
   (match [prev-state item]
     ;; Two comments without a blank line become a paragraph:
     [(c1 :guard n/comment?) (c2 :guard n/comment?)]
     (make-paragraph (str (:s c1) (:s c2)))

     ;; A paragraph followed by a comment grows the paragraph:
     [(c1 :guard paragraph?) (c2 :guard n/comment?)]
     (make-paragraph (str (:s c1) (:s c2)))
     :else "something else")))
#+END_SRC

Code blocks are slightly uglier in Org Mode, and there are many variations.
We'll stick with one of the simplest.

#+BEGIN_SRC
(defn- code-block [s]
  (format "\n#+BEGIN_SRC\n%s\n#+END_SRC\n" s))
#+END_SRC

When we encounter a comment, we strip the leftmost semicolons.

#+BEGIN_SRC
(defn- strip-comment [s]
  (-> s
      str/trim-newline
      (str/replace #"^;+\s*" "")))
#+END_SRC


#+BEGIN_SRC
(defn- paragraphs [items]
  (->> items
       (partition-by nil?)
       (map (partial str/join "\n"))
       (remove #(= % ""))))
#+END_SRC


#+BEGIN_SRC
(defn- process-node [[acc items] node]
  (case (n/tag node)
    :comment [acc (conj items (strip-comment (n/string node)))]
    :newline (if (and (seq items)
                      (some? (peek items)))
               [acc (conj items nil)]
               [acc items])
    :whitespace [acc items]
    :comma [acc items]

    ;; Else,
    [(conj acc {:paragraphs (paragraphs items)
                :form-string (n/string node)
                :form (n/sexpr node)}) []]))
#+END_SRC


#+BEGIN_SRC
(defn- add-paragraphs [acc items]
  (conj acc {:paragraphs (paragraphs items)}))
#+END_SRC


#+BEGIN_SRC
(defn parse-forms-and-comments [source]
  (->> source
       parse-string-all
       n/children
       (reduce process-node [[] []])
       (apply add-paragraphs)))
#+END_SRC


#+BEGIN_SRC
(defn- entry->org [{:keys [paragraphs form-string]}]
  (not-empty
   (str (when (seq paragraphs)
          (str (str/join "\n\n" paragraphs) "\n"))
        (when form-string
          (code-block form-string)))))
#+END_SRC


#+BEGIN_SRC
(defn- base-file-name [file-name]
  (-> file-name java.io.File. .getName))
#+END_SRC


#+BEGIN_SRC
(defn- org-preamble [file-name]
  (format "#+TITLE: ~%s~\n#+OPTIONS: toc:nil num:nil\n"
          (base-file-name file-name)))
#+END_SRC


#+BEGIN_SRC
(defn ->org [file-name forms-and-comments]
  (str (org-preamble file-name)
       (str/join "\n" (keep entry->org forms-and-comments))))
#+END_SRC

Generally, we want to make a ~.org~ file next to the input file:

#+BEGIN_SRC
(defn- org-file-name [fname]
  (str/replace (str fname)
               #"\.[^.]+$"
               ".org"))
#+END_SRC


#+BEGIN_SRC
(def cli-options
  [["-o" "--output FILE" "Output file"
    :parse-fn str]])
#+END_SRC


#+BEGIN_SRC
(defn -main [& args]
  (let [{:keys [options arguments]} (cli/parse-opts args cli-options)]
    (doseq [f arguments
            :let [orgfile (or (:output options)
                              (org-file-name f))]]
      (->> f
           slurp
           parse-forms-and-comments
           (->org f)
           (spit orgfile)))))
#+END_SRC
